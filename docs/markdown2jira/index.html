Converts Markdown to Jira wiki markup, with configurable parsing rules and rendering.

Args
-----=
rules
The Markdown parsing rules to use. Defaults to the GitHub preset (tables, task lists, strikethrough, auto-links, footnotes).
renderer
The renderer used to turn the parsed Markdown into Jira wiki markup. Defaults to JiraRenderer. Subclass JiraRenderer to support custom node types.
plugins
Wenmode plugins to extend parsing with, e.g. for custom syntax.
positions
Whether to track source positions on parsed nodes.
